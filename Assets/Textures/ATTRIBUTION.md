# Texture attribution

The Unity project uses 1K textures from Poly Haven, licensed CC0 1.0:

- forest_ground_04 — https://polyhaven.com/a/forest_ground_04
- bark_brown_02 — https://polyhaven.com/a/bark_brown_02
- forest_leaves_03 — https://polyhaven.com/a/forest_leaves_03
- mossy_rock — https://polyhaven.com/a/mossy_rock

Downloaded maps are in Assets/Textures. The scene generator assigns their diffuse, OpenGL normal and roughness maps to Unity Standard materials.
